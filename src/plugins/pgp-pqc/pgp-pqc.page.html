Composite PGP-PQC (ML-KEM-768 + ML-DSA-65) with OnlyKey

Generate a composite key here, then load it onto your device with the command line. This app cannot load the key itself - writing a private key needs the device's config mode over the vendor interface, which a browser has no access to. Decrypt and sign then run against the device in the slot you loaded it into.

Put the device in config mode first (hold button 6 for 5+ seconds, then enter your PIN); setpqc is refused outside it and now says so instead of reporting success. If you would rather keep the key in a file, use the download above and run onlykey-cli setpqc RSA<slot> <file>, or load an armored composite private key directly with onlykey-cli loadpqc <key.asc> RSA<slot>.
